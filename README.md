# NOVEX PROJECT Portal

Современный портал для MTA:SA-проекта NOVEX PROJECT на React 18 + Vite.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`, предпросмотр: `npm run preview`.

В проекте доступны маршруты главной страницы, новостей, магазина с корзиной, VIP-тарифов, правил и лидерборда. Данные сейчас моковые и готовы для подключения API.

## Стек

React, Vite, TypeScript-ready architecture, React Router, Framer Motion, Lucide React, responsive CSS, dark NOVEX design system.
